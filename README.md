A make.fun [ai-excited-01](https://make.fun/c/ai-excited-01) entry.

**The concept:** a single diagonal matchstick, struck at dawn, whose flame
is a whole rising sun over a dark sea — a tiny match lighting a giant sun.
One focal shape, diagonal momentum, a scale twist, and no text. The image
is drawn from scratch by `main.py` (pure Python standard library, fully
deterministic) — no image files are bundled.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

That writes a 1024×1024 PNG to `out/entry.png` (about 197 KB, well under
the 1 MiB limit). Run it twice and the bytes are identical.
